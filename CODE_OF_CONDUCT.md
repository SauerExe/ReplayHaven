# Code of conduct

Be kind and constructive. This project is maintained in spare time.

- Assume good intent, disagree on the substance, and keep it respectful.
- Harassment, personal attacks and discriminatory remarks are not tolerated anywhere in
  this project, including issues, pull requests and discussions.
- Maintainers may edit, hide or remove contributions that break these rules and may block
  repeat offenders.

If you experience or witness unacceptable behaviour, contact the maintainers privately via
GitHub's "Report content" feature or the security contact in SECURITY.md.
